
# Karthikeyan S - Portfolio Website

A modern portfolio website showcasing my skills, projects, and services as a Full-Stack Developer and UI/UX Designer.

## About This Project

This portfolio website is built with:

- React
- TypeScript
- Tailwind CSS
- shadcn-ui components

## Features

- Responsive design that looks great on all devices
- Modern UI with smooth animations
- Sections for About, Skills, Services, Projects, and Contact
- Contact form for easy communication

## Getting Started

To run this project locally:

```sh
# Clone the repository
git clone https://github.com/Karthikeyan-S6/portfolio-website.git

# Navigate to the project directory
cd portfolio-website

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Deployment

This site is deployed using GitHub Pages.
